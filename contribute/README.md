# Contribute

This folder is a set of short pointers into the full contributor guide on
kubevela.io. Start at [CONTRIBUTING.md](../CONTRIBUTING.md) for the
current front door, covering the Code of Conduct, ways to contribute, DCO,
and links to governance, security, and communication. The
[full contributor guide](https://kubevela.io/docs/contributor/overview)
covers everything in more depth.

- [Developer guide](./developer-guide.md), local setup and how to build and test KubeVela.
- [Coding conventions](./coding-conventions.md), Go, Bash, API, and logging conventions.
- [Create a pull request](./create-pull-request.md), commit format and the PR checklist.
- [Test code guidance](./testcode-guidance.md), unit, integration, and e2e test principles.
- [Triage issues](./triage-issues.md), how issues get labeled and prioritized.
